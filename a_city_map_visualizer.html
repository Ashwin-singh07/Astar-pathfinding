PathMind AI — Algorithmic Architecture & Heuristic Specification

1. Best-First Evaluation Function

At each expansion cycle, the solver selects the frontier node n that minimizes the total estimated path cost:

f(n) = g(n) + h(n)
  • g(n) — Exact accumulated highway distance (plus optional transit toll weights) from the Origin node to n.
  • h(n) — Spatial heuristic estimate of the remaining distance from n to the Target node.
Admissible Heuristics

When h(n) ≤ h*(n) (straight-line Euclidean distance never overestimates physical road distance), A* is mathematically guaranteed to terminate with the globally optimal path while pruning unpromising subtrees.

Edge Relaxation & Branch Switching

When a direct low-h(n) corridor encounters high road weights (such as the Heuristic Trap & Mountain Pass topology), its f(n) exceeds alternative frontier entries, triggering automatic priority-queue branch switching.
